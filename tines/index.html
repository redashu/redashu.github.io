🧭 Track 1 — Lab Setup Requirements

1 Core Environment (Per Student)

  • ✓
    1× Dedicated Virtual Machine (VM) or VDI
  • ✓
    Google Chrome or Mozilla Firefox installed on the VM Tines is fully web-based.
  • ✓
    1× Clean Corporate/Lab Email Address e.g. student01@labdomain.com
  • ✓
    1× Text/Code Editor (VS Code or Notepad++) To edit and format JSON payloads.
  • ✓
    1× API Client (Postman or Bruno) For manual cURL testing before bringing requests into Tines.
Crucial: Avoid generic public emails like Gmail/Outlook when creating accounts — Tines handles corporate email suffixes better during automated setup.

2 Collaboration & Alert Destinations (Per Student)

  • ✓
    1× Dedicated Slack Workspace or Microsoft Teams Sandbox Each student needs admin/creator access to their own channel/workspace to freely create Incoming Webhooks and Custom Apps/Bots to receive Tines alerts.

3 Third-Party Sandbox Application Accounts (Per Student)

  • ✓
    1× Free Tines Community Edition Tenant Registered using the student's lab email address.
  • ✓
    1× Free GitHub Account Registered with the lab email. Used via the GitHub REST API as a free alternative to Jira — creating, updating, and closing "Issues" as tickets during incident response workflows.
  • ✓
    1× Free VirusTotal Community API Key Used during Day 4 & Day 5 enrichment labs to look up file hashes, IPs, and domains — no premium threat-intel licensing needed.

4 Instructor-Provided Datasets (Stored on the VMs)

Place a folder on each student's desktop containing the following pre-built JSON test files:

phishing_intake.json

A raw email structure containing headers, body text, and an embedded malicious URL.

edr_alerts_batch.json

A tiny JSON array of exactly 5 elements (IPs and hostnames) to safely test Explode/Implode without exhausting the 25,000 monthly event limit.

malformed_data.json

An intentionally broken payload with missing keys, null fields, and inconsistent date formats (YYYY-MM-DD mixed with Epoch timestamps) — used for the formula clinic troubleshooting labs.
